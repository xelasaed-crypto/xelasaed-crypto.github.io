Magnitudes & Variables
theory

A magnitude is anything that can be measured: length, mass, temperature, pressure, etc.

“It is characteristic of a magnitude that it can be measured… Measurement results in an abstract number being obtained.”

A variable is a magnitude that can take different values. We often denote it by x, t, etc.

Typical domains of variation:

  • (a, b) – open interval
  • [a, b] – closed interval
  • (a, +∞), (-∞, b] – unbounded intervals
x ∈ [0, 1]      // x varies between 0 and 1
t ∈ (0, +∞)     // time t is positive
p ∈ (0.1, 5]    // pressure p has a physical lower bound
Functions & Dependence
theory

When one variable depends on another, we write y = f(x).

“There must be a law which enables the corresponding value to be found… This is a function.”

Example (Boyle’s law at constant temperature):

v = C / p      // volume v is a function of pressure p

We distinguish:

  • Independent variable – chosen freely (e.g. p)
  • Dependent variable – determined by the law (e.g. v)

Functional relationships can be represented:

Analytically (formula) Tabularly (table) Graphically (curve)

Increments

Given a function y = f(x), the increment of x is

Δx = x₂ − x₁

The corresponding increment of y is

Δy = f(x₂) − f(x₁)

Later, this will lead to the concept of the derivative.

Exercise 3 – Linear interpolation

Given two points (x₁, y₁), (x₂, y₂), write the formula for the straight line through them.

The line is y = y₁ + (y₂ − y₁) * (x − x₁) / (x₂ − x₁).
