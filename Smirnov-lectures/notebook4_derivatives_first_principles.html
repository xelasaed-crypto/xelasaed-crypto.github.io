Increment & Difference Quotient
theory

Given a function y = f(x), the increment of x is

Δx = h

The corresponding increment of y is

Δy = f(x + h) − f(x)

The difference quotient is

(f(x + h) − f(x)) / h

It represents the slope of the secant line through the points (x, f(x)) and (x + h, f(x + h)).

Definition of the Derivative
theory

The derivative of f at x is the limit of the difference quotient as h → 0:

f'(x) = lim_{h→0} (f(x + h) − f(x)) / h

Geometrically, f'(x) is the slope of the tangent line to the graph at the point (x, f(x)).

“The derivative gives the instantaneous rate of change of the function with respect to the variable.”
Example: f(x) = x²
theory

For f(x) = x², we have

(f(x + h) − f(x)) / h
= ((x + h)² − x²) / h
= (x² + 2xh + h² − x²) / h
= (2xh + h²) / h
= 2x + h

Taking the limit as h → 0 gives

f'(x) = 2x

Exercises (Interactive Hints)

Exercise 1 – Derivative of x² at x = 3

Use the numeric derivative tool with f(x) = x² at x = 3. What value does the quotient approach?

Analytically, f'(x) = 2x, so f'(3) = 6. Check that the quotients approach 6.
Exercise 2 – Derivative of x³

Take f(x) = x³. Use the numeric derivative at several points (x = 0, 1, 2). Guess a formula for f'(x).

You should see values close to 0, 3, 12. This suggests f'(x) = 3x².
Exercise 3 – Tangent to sin(x)

Let f(x) = sin(x). Use the tools at x = 0 and x = π/4. What are the slopes of the tangents?

The derivative of sin(x) is cos(x). So slopes are cos(0) = 1 and cos(π/4) = √2/2.
Exercise 4 – Secant vs Tangent

For f(x) = x² at x = 1, vary h in the difference quotient explorer. Watch how the secant line approaches the tangent.

As h gets smaller, the secant slope approaches 2, which is the tangent slope at x = 1.
