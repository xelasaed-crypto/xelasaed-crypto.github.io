Substitution Rule
theory

If u = φ(x) is differentiable and φ'(x) exists, then

∫ f(φ(x)) φ'(x) dx = ∫ f(u) du

We change variables so that the integrand becomes simpler in u.

“Spot a chain rule in reverse: something of the form f(g(x))·g'(x).”
Integration by Parts
theory

From the product rule (uv)' = u'v + uv', we get

∫ u dv = uv − ∫ v du

Choose u to simplify when differentiated, dv to be easily integrable.

Parts:

Standard Examples

Substitution Examples
theory
∫ cos x dx = sin x + C
∫ e^{ax} dx = (1/a) e^{ax} + C
∫ (ax + b)^n dx = (ax + b)^{n+1} / (a (n+1)) + C
Parts Examples
theory
∫ x e^x dx = x e^x − ∫ e^x dx = (x − 1) e^x + C
∫ x sin x dx = −x cos x + ∫ cos x dx = −x cos x + sin x + C
∫ ln x dx = x ln x − x + C

u = ln x, dv = dx ⇒ du = (1/x) dx, v = x.
