Sequences
theory

A sequence (aₙ) is a function n ↦ aₙ defined on ℕ.

Limit: aₙ → L  ⇔  for every ε > 0, ∃N s.t. n ≥ N ⇒ |aₙ − L| < ε.

We study monotonicity, boundedness, and convergence.

Series
theory

Given (aₙ), the series ∑ aₙ is defined via partial sums

Sₙ = a₁ + a₂ + … + aₙ

If Sₙ → S as n → ∞, the series converges to S; otherwise it diverges.

Basic Series Types
theory
Geometric: ∑ rⁿ converges ⇔ |r| < 1, sum = 1/(1−r)
Harmonic: ∑ 1/n diverges
p-series: ∑ 1/n^p converges ⇔ p > 1

Summary: Main Convergence Tests

Key Tests
reference
TestConditionConclusion
Ratio L = lim |aₙ₊₁/aₙ| L < 1 ⇒ convergent; L > 1 ⇒ divergent; L = 1 ⇒ inconclusive
Root L = lim √[n]{|aₙ|} L < 1 ⇒ convergent; L > 1 ⇒ divergent; L = 1 ⇒ inconclusive
Alternating bₙ decreasing, bₙ → 0 ∑ (−1)ⁿ bₙ convergent
p-series ∑ 1/n^p Convergent ⇔ p > 1

Exercises (Interactive Hints)

Exercise 1 – Harmonic vs p-series

Compare ∑ 1/n and ∑ 1/n² using the series explorer and partial sum plot.

Harmonic diverges slowly; 1/n² converges quickly to π²/6.
Exercise 2 – Ratio Test

Use the ratio test on aₙ = 1/n! and aₙ = 1/n.

For 1/n!, ratio → 0 (convergent). For 1/n, ratio → 1 (inconclusive).
Exercise 3 – Alternating Harmonic

Use the alternating test on bₙ = 1/n and see convergence of ∑ (−1)ⁿ/n.

bₙ decreases to 0, so the alternating harmonic series converges (conditionally).
