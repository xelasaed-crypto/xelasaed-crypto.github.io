Basic Rules
theory

Let f, g be differentiable functions, c a constant.

1. (c)' = 0
2. (xⁿ)' = n xⁿ⁻¹
3. (c f(x))' = c f'(x)
4. (f(x) + g(x))' = f'(x) + g'(x)

These rules allow us to differentiate polynomials and linear combinations easily.

Product, Quotient, Chain
theory
5. (f g)' = f' g + f g'
6. (f / g)' = (f' g − f g') / g²
7. (F∘u)'(x) = F'(u(x)) · u'(x)

Rule (5) is the product rule, (6) the quotient rule, (7) the chain rule.

“The derivative of a composite function is the product of the derivative of the outer function and the derivative of the inner function.”
Elementary Functions
theory
(d/dx) sin x = cos x
(d/dx) cos x = −sin x
(d/dx) tan x = sec² x

(d/dx) eˣ = eˣ
(d/dx) aˣ = aˣ ln a

(d/dx) ln x = 1/x
(d/dx) √x = 1 / (2√x)

Combining these with the rules above gives derivatives of many complicated expressions.

Exercises (Interactive Hints)

Exercise 1 – x³ sin x

Differentiate f(x) = x³ sin x using the product rule.

Let f(x) = x³, g(x) = sin x. Then (fg)' = f'g + fg'.
Exercise 2 – √(x² + 1)

Differentiate f(x) = √(x² + 1) using the chain rule.

Write f(x) = (x² + 1)^{1/2}. Take F(u) = u^{1/2}, u(x) = x² + 1.
Exercise 3 – Rational function

Differentiate f(x) = (x² + 1)/(x − 3) using the quotient rule.

Let f(x) = x² + 1, g(x) = x − 3. Then (f/g)' = (f'g − fg')/g².
Exercise 4 – e^{sin x}

Differentiate f(x) = e^{sin x} using the chain rule.

Take F(u) = e^u, u(x) = sin x. Then f'(x) = e^{sin x} cos x.
