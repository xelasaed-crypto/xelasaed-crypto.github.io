General Strategy
theory

Many applied problems reduce to optimizing a function on an interval.

1. Translate the problem into a function f(x)
2. Determine the domain (constraints)
3. Find critical points in the domain
4. Evaluate f at critical points and endpoints
5. Choose the maximum or minimum value
“Optimization is just calculus plus a good translation from words to formulas.”
Example: Rectangle with Fixed Perimeter
theory

Perimeter P fixed, rectangle sides x and y.

P = 2x + 2y  ⇒  y = P/2 − x
Area: A(x) = x y = x(P/2 − x)

We maximize A(x) on 0 < x < P/2.

A'(x) = P/2 − 2x = 0  ⇒  x = P/4
Then y = P/4  ⇒  square gives maximal area.
Example: Box with No Lid
theory

Square base side x, height h, volume V fixed.

V = x² h  ⇒  h = V / x²
Surface (no lid): S(x) = x² + 4 x h
= x² + 4x (V / x²) = x² + 4V / x

We minimize S(x) for x > 0.
