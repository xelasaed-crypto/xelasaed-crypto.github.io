Definition & Notation
theory

An antiderivative of f(x) is a function F(x) such that

F'(x) = f(x)

The set of all antiderivatives is written as the indefinite integral:

∫ f(x) dx = F(x) + C
“Differentiation is precise; integration is ambiguous up to a constant.”
Basic Rules
theory
∫ 0 dx = C
∫ k dx = kx + C
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C   (n ≠ −1)
∫ 1/x dx = ln|x| + C
∫ eˣ dx = eˣ + C
∫ cos x dx = sin x + C
∫ sin x dx = −cos x + C
∫ 1/(1+x²) dx = arctan x + C

Linearity:

∫ (af(x) + bg(x)) dx = a ∫ f(x) dx + b ∫ g(x) dx
Geometric Meaning
theory

If F'(x) = f(x), then F(x) can be seen as “accumulated area” under f:

F(x) = ∫ f(t) dt + constant

Later, the definite integral will make this precise as area between the graph and the x-axis.
