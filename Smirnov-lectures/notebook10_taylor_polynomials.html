Taylor’s Theorem (Lagrange Remainder)
theory

Let f have n+1 continuous derivatives near a point a. Then for x near a:

f(x) = Tₙ(x) + Rₙ(x)

Tₙ(x) = f(a)
      + f'(a)(x−a)
      + f''(a)/2! (x−a)²
      + … + f⁽ⁿ⁾(a)/n! (x−a)ⁿ

Rₙ(x) = f⁽ⁿ⁺¹⁾(ξ)/(n+1)! · (x−a)ⁿ⁺¹
for some ξ between a and x
“Taylor polynomial is the best local polynomial ‘shadow’ of a smooth function.”
Maclaurin Series
theory

Maclaurin series is Taylor series at a = 0.

eˣ   = 1 + x + x²/2! + x³/3! + …
sin x = x − x³/3! + x⁵/5! − …
cos x = 1 − x²/2! + x⁴/4! − …
ln(1+x) = x − x²/2 + x³/3 − …  (|x| < 1)
(1+x)^p = 1 + px + p(p−1)x²/2! + …

Convergence depends on x and the function; sometimes the series converges but not to f(x).

Error Bounds & Convergence
theory

If |f⁽ⁿ⁺¹⁾(t)| ≤ M on an interval containing a and x, then

|Rₙ(x)| ≤ M |x−a|ⁿ⁺¹ / (n+1)!

For alternating series (like sin x, cos x), the error is bounded by the first neglected term.

Sometimes the Taylor series converges for all x (e.g. eˣ), sometimes only for |x| < R.
