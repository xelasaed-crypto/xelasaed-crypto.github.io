Rolle & Lagrange MVT
theory

Rolle’s theorem. If

  • f is continuous on [a, b]
  • f is differentiable on (a, b)
  • f(a) = f(b)

then there exists c ∈ (a, b) such that

f'(c) = 0

Lagrange’s Mean Value Theorem. If f is continuous on [a, b] and differentiable on (a, b), then

∃ c ∈ (a, b) such that
f'(c) = (f(b) − f(a)) / (b − a)
“There is at least one point where the instantaneous slope equals the average slope.”
Cauchy MVT & Inequalities
theory

Cauchy’s Mean Value Theorem. If f, g are continuous on [a, b], differentiable on (a, b), and g'(x) ≠ 0 on (a, b), then

∃ c ∈ (a, b) such that
(f'(c) / g'(c)) = (f(b) − f(a)) / (g(b) − g(a))

From MVT we get inequalities. If |f'(x)| ≤ M on [a, b], then

|f(x) − f(a)| ≤ M |x − a|   for all x ∈ [a, b]

This is a Lipschitz-type bound.

Monotonicity & Comparison
theory

If f'(x) ≥ 0 on (a, b), then f is non-decreasing on [a, b]. If f'(x) ≤ 0, then f is non-increasing.

f'(x) > 0 on (a, b) ⇒ f strictly increasing
f'(x) < 0 on (a, b) ⇒ f strictly decreasing

Using Cauchy MVT, we can compare growth of two functions.

Exercises (Interactive Hints)

Exercise 1 – Linear Bound

Let |f'(x)| ≤ 3 on [0, 2]. Show that |f(2) − f(0)| ≤ 6.

Apply MVT to f on [0, 2]: f(2) − f(0) = f'(c)·2 for some c. Then |f'(c)| ≤ 3.
Exercise 2 – Monotonicity

If f'(x) ≥ 1 on [0, 5], show that f(5) − f(0) ≥ 5.

MVT: f(5) − f(0) = f'(c)·5 with c ∈ (0, 5). Since f'(c) ≥ 1, the difference is ≥ 5.
Exercise 3 – sin x Inequality

Use the sin inequality tester to explore |sin x − sin a| ≤ |x − a|.

Note that |(sin x)'| = |cos x| ≤ 1, then apply the general inequality with M = 1.
Exercise 4 – Constant Derivative

If f'(x) = 0 on (a, b), use MVT to show f is constant on [a, b].

For any x, y in [a, b], apply MVT on [x, y]: f(y) − f(x) = f'(c)(y − x) = 0.
