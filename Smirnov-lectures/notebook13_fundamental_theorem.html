First Fundamental Theorem
theory

Let f be continuous on [a, b]. Define

F(x) = ∫ₐˣ f(t) dt

Then F is differentiable and

F'(x) = f(x)
“Differentiation undoes integration when the upper limit moves.”
Second Fundamental Theorem
theory

If F is any antiderivative of f on [a, b], then

∫ₐᵇ f(x) dx = F(b) − F(a)

This turns definite integrals into a difference of antiderivatives.

Integrals with Variable Limits
theory

For

G(x) = ∫_{α(x)}^{β(x)} f(t) dt

and smooth α, β, we have

G'(x) = f(β(x)) β'(x) − f(α(x)) α'(x)

(Leibniz rule for differentiation under the integral sign with variable limits.)

Exercise 1 – F'(x) = f(x)

Take f(t) = cos t, a = 0. Define F(x) = ∫₀ˣ cos t dt. Check numerically that F'(x) ≈ cos x.

Exact F(x) = sin x, so F'(x) = cos x.
Exercise 2 – Evaluate via Antiderivative

F(x) = x⁴/4, so ∫₀¹ x³ dx = 1/4.
