Intuition of a Limit
theory

We say that lim_{x→a} f(x) = L if the values of f(x) get arbitrarily close to L when x is taken sufficiently close to a.

“The limit of a function is the value which the function approaches as the variable approaches a given point.”

Important: the value of f(a) (if it exists) may be different from the limit, or even undefined.

f(x) = (x² − 1) / (x − 1)
lim_{x→1} f(x) = 2
but f(1) is not defined (division by zero)
Left & Right Limits
theory

We distinguish:

  • lim_{x→a^-} f(x) – from the left
  • lim_{x→a^+} f(x) – from the right

The limit exists (and equals L) if both one-sided limits exist and are equal to L.

f(x) = { 1, x < 0
       { 2, x ≥ 0

lim_{x→0^-} f(x) = 1
lim_{x→0^+} f(x) = 2
⇒ lim_{x→0} f(x) does not exist
Continuity
theory

A function f is continuous at a point a if:

  • f(a) is defined
  • lim_{x→a} f(x) exists
  • lim_{x→a} f(x) = f(a)

Geometrically: the graph has no “jump” or “hole” at x = a.

Exercise 1 – Removable discontinuity

Consider f(x) = (x² − 1)/(x − 1). What is lim_{x→1} f(x)? Is f continuous at x = 1?

Use the numeric limit explorer at a = 1. Then simplify algebraically: (x² − 1)/(x − 1) = x + 1 for x ≠ 1.
Exercise 2 – Jump discontinuity

Define a piecewise function: f(x) = 1 for x < 0, f(x) = 2 for x ≥ 0. What are the left and right limits at 0?

You can’t encode the piecewise function directly here, but reason: approaching 0 from negative side gives 1, from positive side gives 2.
Exercise 3 – sin(x)/x

Investigate f(x) = sin(x)/x near x = 0. What does the numeric limit suggest?

Use the numeric limit explorer with sin(x)/x and a = 0 (in radians). The limit is known to be 1.
Exercise 4 – Continuity check

For f(x) = x², check continuity at x = 2 using the continuity checker.

Set f(x) = x*x, a = 2. Left and right numeric limits should both be close to 4, and f(2) = 4.
