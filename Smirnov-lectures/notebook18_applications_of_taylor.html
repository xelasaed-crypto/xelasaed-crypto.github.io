Taylor for Limits
theory

Near a point a, replace f(x) by its Taylor polynomial to simplify limits.

Example:  lim_{x→0} (sin x)/x
sin x = x − x³/3! + O(x⁵)
⇒ (sin x)/x = 1 − x²/3! + O(x⁴) → 1

This is “L’Hôpital by series”.

Asymptotic Expansions
theory

We write f(x) ~ g(x) as x → a if f(x)/g(x) → 1.

sin x ~ x,   1 − cos x ~ x²/2,   ln(1+x) ~ x

Taylor gives systematic asymptotics.

Remainder (Lagrange Form)
theory

For f ∈ C^{N+1} near a,

f(x) = T_N(x) + R_N(x),
R_N(x) = f^{(N+1)}(ξ)/(N+1)! · (x − a)^{N+1}

for some ξ between a and x. This bounds the error.

Exercises (Interactive Hints)

Exercise 1 – Classic Limit

Use the limit panel to justify lim_{x→0} (1 − cos x)/x² = 1/2.

cos x = 1 − x²/2 + O(x⁴) ⇒ 1 − cos x = x²/2 + O(x⁴).
Exercise 2 – ln(1+x)

Check ln(1+x) ≈ x − x²/2 for small x and see error vs N.

ln(1+x) = x − x²/2 + x³/3 − …; truncation error behaves like next term.
Exercise 3 – Error Decay

Use the error-vs-N plot for e^x at x = 1 and watch how fast it drops.

For entire functions like e^x, Taylor converges for all x, with factorial in denominator.
