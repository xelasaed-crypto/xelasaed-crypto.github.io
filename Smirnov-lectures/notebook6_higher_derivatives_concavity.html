Higher-Order Derivatives
theory

If f'(x) is differentiable, its derivative is the second derivative:

f''(x) = (f'(x))'

Similarly we define f'''(x), f⁽⁴⁾(x), …, f⁽ⁿ⁾(x).

Example: for f(x) = x³:

f'(x)  = 3x²
f''(x) = 6x
f'''(x)= 6
f⁽⁴⁾(x)= 0
Concavity & Second Derivative
theory

The sign of f''(x) describes the curvature of the graph:

f''(x) > 0  ⇒  f is convex (concave up)
f''(x) < 0  ⇒  f is concave (concave down)

Geometrically: concave up looks like a “cup”, concave down like a “cap”.

“The second derivative measures how the slope itself changes.”
Points of Inflection
theory

A point x = a is a point of inflection if the concavity changes:

  • f''(x) changes sign at a
  • the graph passes from concave up to concave down or vice versa

Often we solve f''(x) = 0 and then check the sign of f'' on each side.

Example: f(x) = x³ has f''(x) = 6x, so x = 0 is an inflection point.

Exercises (Interactive Hints)

Exercise 1 – Concavity of x³

Use the concavity visualizer with f(x) = x³. Where is the function concave up and concave down?

Compute f''(x) = 6x. It is negative for x < 0 and positive for x > 0.
Exercise 2 – Inflection of x³

Use the inflection finder for f(x) = x³ on [-3, 3]. What x-value is detected?

The sign of f''(x) = 6x changes at x = 0, so (0, 0) is an inflection point.
Exercise 3 – x⁴

Investigate f(x) = x⁴. Does it have an inflection point at x = 0?

f''(x) = 12x² ≥ 0 for all x, so the concavity does not change at 0.
Exercise 4 – sin x

Use the concavity visualizer for f(x) = sin x. Where are the inflection points?

Since f''(x) = −sin x, inflection points occur where sin x = 0, i.e. at multiples of π.
