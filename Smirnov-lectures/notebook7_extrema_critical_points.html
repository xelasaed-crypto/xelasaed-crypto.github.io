Critical Points
theory

A point x = a is a critical point of f if

f'(a) = 0   or   f'(a) does not exist

Local maxima and minima can only occur at critical points (or endpoints of an interval).

“Derivative zero means horizontal tangent — a natural place to look for extrema.”
First Derivative Test
theory

Let a be a critical point. Look at the sign of f' around a:

f' changes + → −  ⇒  local maximum at a
f' changes − → +  ⇒  local minimum at a
f' does not change sign ⇒  no extremum (saddle)

This test uses only the first derivative.

Second Derivative Test
theory

If f'(a) = 0 and f''(a) exists:

f''(a) > 0  ⇒  local minimum (concave up)
f''(a) < 0  ⇒  local maximum (concave down)
f''(a) = 0  ⇒  test inconclusive

Then we may need the first derivative test or higher derivatives.

Exercises (Interactive Hints)

Exercise 1 – x³ − 3x

For f(x) = x³ − 3x, find all critical points and classify them.

Solve f'(x) = 3x² − 3 = 0. Then use the second derivative f''(x) = 6x.
Exercise 2 – x⁴ − 2x²

For f(x) = x⁴ − 2x², find and classify critical points.

f'(x) = 4x³ − 4x = 4x(x² − 1). Check x = 0, ±1 with f''(x) = 12x² − 4.
Exercise 3 – sin x

On [0, 2π], find all local maxima and minima of f(x) = sin x.

f'(x) = cos x. Solve cos x = 0 and use f''(x) = −sin x.
Exercise 4 – x² sin x

Use the tools to explore extrema of f(x) = x² sin x near 0 and near π.

Combine product and chain rules for an analytic derivative, then compare with numeric classification.
